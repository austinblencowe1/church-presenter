Church Presenter

Presentation software for churches

Church Presenter is a desktop app for preparing church services and presenting slides to an audience display on Windows and macOS. Built with Tauri 2, Rust, and a modern web frontend, it's designed around the way church services actually flow.

Features

  • Create and organize services, songs, slides, and reusable slide templates
  • Edit slide text, backgrounds, media, and presentation layouts
  • Import PowerPoint and PDF slides into a service
  • Present to a separate audience display with presenter controls
  • Connect Google Drive for service and template sync across devices
