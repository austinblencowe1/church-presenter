Presentation software for churches

Church Presenter is a desktop app for preparing church services and presenting slides to an audience display on Windows, macOS, and Linux. Built with Tauri 2, Rust, and a modern web frontend, it's designed around the natural flow of a church service.

Features

Service Planning

Create and organize services, songs, slides, and reusable slide templates in one place.

Rich Editing

Edit slide text, backgrounds, media, and presentation layouts with an intuitive interface.

Import & Export

Import PowerPoint and PDF slides into a service, and backup with .cpres files.

Dual Display

Present to a separate audience display with dedicated presenter controls and keyboard shortcuts.

Cloud Sync

Connect Google Drive to sync services and templates across multiple devices.

Built for Churches

Designed specifically for worship services with the tools you actually need.
