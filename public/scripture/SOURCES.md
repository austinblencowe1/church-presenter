# Offline Scripture text sources

This folder contains the King James Version (KJV) and World English Bible (WEB) in JSON format from the `midvash/bible-data` project.

- Source repository: https://github.com/midvash/bible-data
- KJV data and metadata: https://github.com/midvash/bible-data/tree/main/versions/en/kjv
- WEB data and metadata: https://github.com/midvash/bible-data/tree/main/versions/en/web
- Repository code is MIT licensed. Each translation's `*-metadata.json` records its text license and provenance; both included texts are marked public domain.

The translation JSON files are bundled locally so reference and phrase search work offline.
